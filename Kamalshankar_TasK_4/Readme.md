# Task-4 CSS Units, Box Models & Fonts

- I create a simple webpage using CSS viewport units, box sizing and gradient. No flexbox, no hidden overlfows, just clean flowing layout. 

## About project 
- This project is on CSS Units, Box Models & Fonts. i have use all of these in it like.
- viewport height, viewport width
- boxsizing
- Fonts size, color

### Container part 
- The container place in center — 10vh space from top & bottom, 25vw from right & left.
- image using 100% width of the container for flexiblity.
- in button section i use anchor tag outside the button tag for get the access of the whole button. and for gardient in button i use background-image property key and the property type is linear-gradient.

## What I avoided

- No flexbox (took some effort but I managed)
- No overflow hidden
- No position absolute or relative

* Everything just flows naturally.
